# Application Architecture

## Overview

HealthMate AI is a Streamlit application organized into three main layers:

1. **Presentation:** `app.py` manages page navigation, user input, language selection, and response display.
2. **Application service:** `services/ai_service.py` handles configuration, initializes the Gemini chat client, and generates health information in the selected language.
3. **Utilities:** `utils/response_parser.py` separates the generated response into sections for display.

## Request Flow

```text
User
  |
  v
Streamlit UI (app.py)
  |
  v
AI Service (services/ai_service.py)
  |
  v
Google Gemini API
  |
  v
Generated response in selected language
  |
  v
Response Parser (utils/response_parser.py)
  |
  v
Streamlit displays the sections
```

## Configuration

The application reads its API credential from the `GOOGLE_API_KEY` environment variable.

The optional `GEMINI_MODEL` environment variable selects the Gemini model. If omitted, the application defaults to `gemini-3.5-flash-lite`.

Configuration values can be provided through a local `.env` file using `python-dotenv`.

## Scope and Limitations

- Users can request general health information in English, Hindi, or Gujarati.
- The application does not persist user symptom submissions or maintain a database.
- The original project included a Wikipedia summary helper, but it was not connected to the active application workflow and is not included in this refactored version.
- Responses are generated by a large language model and should not be treated as medical diagnoses or professional medical advice.
